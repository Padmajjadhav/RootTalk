# RootTalk: Digital Preservation of Regional Languages and Dialects

> A Community Engagement Project (CEP) bridging grassroots cultural preservation with modern computer science[cite: 1].

---

## 📌 About the Project
Regional languages and local dialects form the bedrock of cultural identity, carrying centuries of indigenous wisdom, ecological knowledge, and oral traditions[cite: 1]. However, rapid globalization, urbanization, and digital marginalization threaten many regional dialects with language attrition[cite: 1]. 

**RootTalk** is a community-driven digital repository designed to capture rare vocabulary, idioms, folk stories, and authentic audio recordings from native speakers and elders, preserving them systematically for future generations and academic research[cite: 1, 2].

## ⚙️ Project Workflow & Methodology (45 Hours)
The project was executed across three structured phases:
1. **Phase 1: Preparation & Tool Design (10 Hours):** Formulated data collection instruments, consent protocols, and standardized metadata structures (Word, Part of Speech, Translation, Phonetic Transcription, Contextual Sentence, Audio Reference)[cite: 2].
2. **Phase 2: Field Work & Data Collection (20 Hours):** Conducted on-site interactions with elder native speakers (ages 60-85) to record oral histories, traditional songs, and colloquial expressions[cite: 2, 3].
3. **Phase 3: Technical Implementation & Archival (15 Hours):** Processed audio/text data and deployed a structured database coupled with an interactive web interface[cite: 2].

## 🛠️ Technology Stack

### Frontend Architecture
* **HTML5:** Semantic structure for dictionary sections, audio player cards, and contributor forms[cite: 4].
* **CSS3 (Tailwind CSS / Custom Styling):** Responsive, modern, and accessible design for desktop and mobile devices[cite: 4].
* **Vanilla JavaScript:** Real-time search filtering, dynamic sorting, and asynchronous audio playback control via `HTMLAudioElement`[cite: 4].

### Backend & Database
* **Backend Server:** Python Flask / Node.js & Express API for handling CRUD operations and secure audio file uploads[cite: 4, 5].
* **Database:** PostgreSQL / SQLite relational database for efficient linguistic metadata management[cite: 4, 5].
* **Tools & Utilities:** Kobo Toolbox/Google Forms for mobile surveys, Audacity for audio noise reduction/standardization, and Supabase/GitHub for storage and version control[cite: 5].
